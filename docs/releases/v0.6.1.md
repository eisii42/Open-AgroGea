AgroGea 0.6.1 is a documentation release: every guide now matches the app as it is after 0.5 and 0.6. The app itself does not change.

Full details are in the `[0.6.1]` section of the [CHANGELOG](https://github.com/eisii42/Open-AgroGea/blob/main/CHANGELOG.md).

## Upgrading

- **Nothing to do.** No code, database (v25) or backup-format (v3.1) changes. The desktop app updates itself as usual.

## Documentation

- **English README first.** `README.md` is now the English one (Italian in `README.it.md`), with the 0.6 interface, saved WMS backgrounds, where to download installers and how the project is checked for security.
- **User manuals (English and Italian)**:
  - a new chapter on the screen, on a computer and on a phone, and on the **To do** centre;
  - every path now uses the real names in the app (*Module → Tool*);
  - editing operations and missing data in the logbook;
  - saved WMS backgrounds, the calendar on phones and wide screens, weather in the top bar;
  - `Ctrl K`, `Esc` and keyboard navigation.
- **Architecture**: how the 0.6 interface is built (panel stack, Esc handling, the To do centre) and a map of the app's security boundaries.
- **Contributing guide**: the checks every pull request goes through, how to handle security findings, dependency updates and the release process.
- **Security Policy**: supported versions (0.6.x), updated scope, how the project is protected and the known advisories.
- **Roadmap**: 0.5.0 and 0.6.0 marked as released, the 0.6.x patch plan, and the crop-protection DSS track moved to 0.7.0–0.10.0.
- Technical notes on raster sources (saved WMS, attributions) and on desktop auto-update (release notes, CI platforms).

## Known issues

Unchanged from 0.6.0:
- **MapLibre GL 5.x** is still in use. CVE-2026-85061 is neutralised in the attribution bar; the full fix comes with MapLibre 6.
- **Linux only**: the `glib` advisory GHSA-wrw7-89jp-8q8g will close when Tauri moves to GTK 4.
